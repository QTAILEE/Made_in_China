# FairTurn 公平發言

**Activity of the Day — Option 2：找出常見課堂問題，設計簡單 Web App 解決。**

## 問題與解決方法

全班討論時，往往只有少數學生經常回答，教師難以即時掌握誰仍未獲邀。FairTurn 優先邀請在席且獲邀次數較少的學生，同次數隨機抽選，只在最少獲邀次數的候選人多於一位時避免連續邀請同一人；若唯一的最少獲邀者剛被邀請過，仍會優先補回機會。學生可以分享，也可以暫時跳過；兩者都算一次獲邀機會。覆蓋率呈現機會分配，不用來評分或判斷學習成效。

## 使用流程

1. 教師以座號或暱稱設定 1–60 人名單、班別和討論題目。
2. 點擊學生切換出缺席，或使用「全員在席／全員缺席」。邀請尚未完成時，出缺席與還原操作會鎖定。
3. 給學生 10–60 秒思考，然後邀請一位學生。可暫停計時後手動邀請。
4. 記錄「已分享／暫時跳過」，或取消邀請；誤記可復原上一筆。
5. 投影模式隱藏名單及統計，但會顯示被邀請者的稱呼。
6. 以 CSV 匯出可閱讀的課堂記錄；以 JSON 備份保留可還原的名單、出缺席、討論題目及邀請記錄。

## 本次改進

- 更清楚地說明 App 解決的課堂問題。
- 全班出缺席操作，減少逐一點擊的準備時間。
- 下載課堂備份及還原：選檔後先預覽班別與記錄數目，確認才取代目前課堂。
- 無效或超過 2 MB 的備份會被拒絕，目前課堂保留。最多支援 20,000 筆邀請記錄。
- 新功能提供繁體中文及英文；投影時隱藏備份控制。
- 窄螢幕按鈕可換行，學生名單使用三欄，減少擠迫。

## 資料與限制

無需登入、API 金鑰或資料庫。記錄自動保存在目前瀏覽器的 localStorage，沒有跨裝置同步。轉換裝置前請下載 JSON 備份；CSV 不能用於還原。備份含學生稱呼與課堂記錄，請妥善保管，建議使用座號。若瀏覽器不能儲存，畫面會提示匯出。抽選不是 AI 評分；AI 用於協助設計與編寫 App。

## 開發

不需要安裝依賴或建置。使用現有 checkout，不需要建立 Git worktree。

```sh
cd /workspace/Made_in_China
python3 -m http.server 8000 --bind 127.0.0.1 --directory /workspace/Made_in_China
```

主頁 `index.html`；互動邏輯 `app.js`；公平抽選邏輯 `core.js`。

## 提交可用網站連結

本機啟動不會產生公開連結。以下操作需要儲存庫的發佈權限：

1. 提交並推送這些變更至 `QTAILEE/Made_in_China` 的 `main` 分支。
2. GitHub 儲存庫 Settings → Pages → Deploy from a branch，選 `main` 和 `/(root)`，儲存並等候部署完成。
3. 使用 Pages 畫面實際提供的 HTTPS 網址，在未登入的視窗測試名單、抽選、備份和還原，再提交該網址。
4. 如課程要求 Google Sites，可在「插入 → 嵌入 → 網址」貼上已發布網址，另提供直接開啟 App 的按鈕。發布 Google Sites 後檢查讀者權限。
